What is claude-auto?

claude-auto is a command-line wrapper for Claude Code that rotates between several Claude subscriptions (Pro, Max or Team). It checks each account's real usage, and when the current account reaches its usage limit it resumes the same conversation on the next account with usage left, so your work does not stop.

How to install and set up claude-auto

  1. Install (needs Claude Code, bash, python3, curl): 
    curl -fsSL https://raw.githubusercontent.com/rameezimdad/claude-auto-switch/main/install.sh | bash
  2. Add each extra Claude subscription. Run it once per account, type /login, sign in, then /exit: 
    claude-auto add      # account 2
claude-auto add      # account 3
claude-auto add      # account 4, 5 ... no limit
  3. Work as usual with claude-auto instead of claude. Every Claude Code flag still works.

How does the automatic switch work?

  1. claude-auto starts Claude Code on the first account that is under its limit.
  2. When a turn fails with a usage-limit error, Claude Code's official StopFailure hook checks that account's real usage.
  3. If the account is full, the session is saved and Claude Code closes. A short burst of errors with usage left is ignored.
  4. claude-auto checks the other accounts and reopens the same session on the first one with usage left, bringing checkpoints, todos and plans along.
  5. Claude checks what is already done in your code (git status or the files it was editing) and continues from the next unfinished step. If every account is full, claude-auto waits for the earliest reset.

Frequently asked questions

What to do when the Claude usage limit is reached in Claude Code?

You can wait for the reset (up to 5 hours for the session window, longer for the weekly limit), or use claude-auto, which moves the same Claude Code session to another Claude account you own that still has usage left and continues the task.

How do I use Claude after reaching the limit?

Install claude-auto, add a second Claude account with claude-auto add, and start Claude Code with claude-auto. When the limit is reached it switches accounts automatically.

How do I use multiple Claude accounts in Claude Code?

Each account needs its own config folder (CLAUDE_CONFIG_DIR). claude-auto add creates one that shares your history and settings, and claude-auto picks the account with usage left.

How many Claude accounts can I add to claude-auto?

There is no limit. Run claude-auto add for account 2, 3, 4, 5 and so on. Accounts are tried in order.

Does switching Claude accounts lose my conversation or code progress?

No. claude-auto resumes the same session ID, carries edit checkpoints, todos and plans, and tells Claude to check the current state of the code and continue from the next unfinished step instead of starting over.

What happens when all Claude accounts reach the weekly limit?

claude-auto shows when the earliest account resets, waits until then and continues the session automatically.

How does the Claude usage limit work?

Claude Pro and Max plans have a rolling 5-hour session limit and a weekly limit. claude-auto status shows the percent used and the reset time of each account.
